# Grace Semijoias

Loja estática da Grace com catálogo de semijoias, filtros por categoria, carrinho, cupom e envio do pedido pelo WhatsApp.

## Arquivos

- `index.html`: apresentação da marca e estrutura da loja e do carrinho.
- `css/style.css`: identidade visual em azul-marinho, rosa antigo, creme e dourado.
- `js/produtos.js`: WhatsApp, cupom, categorias e produtos.
- `js/app.js`: filtros, carrinho e cálculo de valores.
- `img/`: fotos das peças da coleção.

## Personalizar produtos e pedidos

Edite `js/produtos.js` para atualizar nomes, preços, descrições, categorias e fotos. Informe em `LOJA.whatsapp` o telefone da Grace com DDI e DDD, somente números, para direcionar os pedidos. O cupom de demonstração `GRACE10` aplica 10% de desconto.

## Visualizar

Abra `index.html` no navegador ou use a extensão Live Server no VS Code.

## Publicar

O site funciona em hospedagens estáticas como GitHub Pages, Netlify ou Vercel.
